单元页：先看课程列表，再自由选择学习

把「点单元直接跳第一课」改为「进入单元页 → 浏览本单元全部课程 → 自由选择任意一课开始」，并在文末给出课程设计的进一步优化建议。

版本v0.1 草案 日期2026-11-02 负责人[TBD] 涉及模块课程地图、单元页、课程详情入口 文档类型常规 PRD（功能迭代）

1背景与目标

现在的问题

课程地图上的「单元详情」卡片和冒险地图里的单元节点，点击后都直接跳进该单元的第一门待学课程。学习者看不到这个单元一共有几课、每课讲什么，也无法选择自己更想先学的那一课。

对自学用户来说，这等于把「单元」变成了一个不透明的快捷入口：想重学某一课，只能靠课程详情页的上一课 / 下一课按钮绕回去。

期望的结果

点击任意单元后，先进入单元页，看到本单元全部课程及各自的主题、内容量和完成状态；学习者可以自由点击任意一课进入学习页，不需要按顺序解锁。

单元页同时保留一个「推荐下一课」的默认入口，让不想做选择的人一键继续。

产品判断

「自由选择」指所有课程都可直接进入，不设解锁门槛。自由不等于无引导：单元页默认高亮本单元第一门未完成课程，作为推荐起点。

2范围

优先级内容说明
P0 新增单元页 /unit/:unitId 展示单元标题、简介、进度与本单元课程列表。
P0 课程列表与自由选择 每门课显示序号、标题、主题、词汇 / 句子 / 题量、完成状态；任意一课可点击进入学习页。
P0 入口改造 课程地图的单元卡片、冒险地图的单元节点改为进入单元页，不再直达第一课。
P0 完成回流 练习页完成后同时提供「下一课」与「返回本单元课程列表」。
P1 推荐下一课标记 单元页高亮第一门未完成课程，并给出「从这里继续」按钮。
不做 解锁 / 前置条件 课程不设任何顺序门槛，已完成课程也可随时重学。
不做 课程内容与题库 只改展示与入口，不新增、不改写课程内容。

3产品模型与核心流程

3.1 对象与路由

对象 / 路由定义关键字段
Unit 单元，包含若干门按顺序排列的课程。 级别、序号、标题、简介、课程 ID 列表
Lesson 单元内的一门课。 序号、标题、目标、词汇量、句子量、题量、完成状态
/learn 课程地图：全部单元的总览入口。 —
/unit/:unitId 单元页：本单元课程列表与单元进度。 —
/lesson/:lessonId 学习页（已上线），由单元页进入。 —

3.2 核心流程

课程地图 / 冒险地图 → 单元页 → 任选一课 · 学习页 → 练习页 → 完成本课

完成本课后可选择「下一课」继续，或「返回本单元」重新选课；课程列表中的任意一课都可直接进入。

4功能需求

FR-01 单元页

P0

路由 /unit/:unitId；目标是在一个页面里完整回答「这个单元有哪些课、我该学哪一课」。

1页面头部

返回课程地图；级别与单元序号；单元标题与简介；单元完成进度（已完成课程数 / 总课程数）与进度条。

2推荐继续

当单元内存在未完成课程时，显示「从这里继续：第 N 课 · 课程标题 →」，点击进入该课学习页。全部完成时改为「本单元已全部完成」状态。

3课程列表

按课程顺序列出本单元全部课程。每行是一个课程卡片，包含序号、标题、主题摘要、内容量、完成状态，并可整行点击进入学习页。

4单元底部

上一单元 / 下一单元导航，方便跨单元浏览；不提供「一键学完本单元」这类批量入口。

规则项行为
单元不存在重定向到课程地图 /learn。
单元内无课程显示空状态「这个单元还没有课程」，并保留返回课程地图入口。
完成状态沿用现有已完成记录：课程 ID 在已完成列表中即显示「已完成」，否则显示「未开始」。
推荐规则取单元内顺序第一门未完成课程；全部完成时不显示推荐按钮。
自由选择不校验任何前置课程，任意课程卡片都可进入；已完成课程同样可进入重学。

FR-04 完成回流

P0
场景行为
完成本课后提供两个入口：「下一课：标题 →」与「返回本单元」；下一课不存在时只保留「返回本单元」。
单元最后一课完成「返回本单元」为主按钮，单元页显示「本单元已全部完成」。
学习页顶部返回「← 返回单元」回到本课所属单元页，而不是课程地图。

5共享规则与异常

规则定义
课程顺序单元内课程仍按既有顺序展示与推荐，但顺序只影响展示，不影响进入权限。
状态口径课程只有「未开始 / 已完成」两种状态，不新增「学习中」等未持久化的状态。
数量口径词汇 = 本课词汇数；句子 = 本课句子数；练习 = 句子练习与课文练习总题量，与练习页顶部一致。
入口一致所有进入课程详情的入口统一先到学习页，再进入练习页，不直接跳练习页。
返回链路单元页 → 学习页 → 练习页，返回时逐级回退，不出现跳回课程地图的断层。
回归检查点

首页「继续学习」仍能直达下一课；单元页与冒险地图的单元节点都能进入单元页；单元页课程卡片的状态与课程地图进度一致；已完成课程可重复进入学习页与练习页。

6课程设计的进一步优化建议

以下为本轮之外的建议，供后续排期参考；括号内为建议优先级。

优先级建议解决什么问题可观察的结果
P1 练习进度持久化 自由选课后学习者更容易中途退出；现在刷新就丢失全部作答。 刷新或返回后恢复已答题目与当前得分，并提供「重新开始」入口。
P1 错题回看与复习联动 答错时只看一次解析，之后无法再定位；错题与句子复习系统彼此独立。 练习结束提供「错题回看」，错题可一键加入复习队列。
P1 单元级学习目标 单元页只有标题和简介，学习者不知道这个单元整体要掌握什么、课程之间如何递进。 单元头部展示「本单元你会学到」：3–5 条能力或语法点，来自现有课程目标汇总。
P2 今日任务适配自由选课 今日任务目前固定为「学 1 新课」，自由选择后可能与实际学习行为不一致。 任意一课完成都计入今日任务；今日任务可展示「今天学了哪一课」。
P2 单元完成回顾页 学完一个单元缺少阶段性收束，只有课程地图上的进度条变化。 单元全部完成时展示本单元掌握情况与下一单元入口。
P2 课程列表筛选与搜索 单元与课程增多后，按顺序翻找某一主题会变慢。 课程地图支持按级别、主题词或完成状态筛选，并可直接定位课程。
不建议现在做

课程解锁门槛、学习时长估算、强制学习顺序。这三类设计会与「自由选择」直接冲突，也会给自学用户增加摩擦。
