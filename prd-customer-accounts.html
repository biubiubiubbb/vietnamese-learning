01背景与目标

当前学习数据只存在单台设备的浏览器里，中后台只管理内容，不知道客户是谁、学得怎么样。

现状

  • 前台学习进度保存在浏览器本地，包含已完成课次、课次测评成绩、词条复习卡（5 盒间隔）和句子复习卡；换设备、换浏览器或清理缓存后进度丢失。
  • 前台没有账号体系，任何访问者都以同一个「本地学员」身份学习，无法区分两个客户。
  • 中后台现有单元、课程、词汇、句子、发音、音频等内容管理能力，但没有任何客户维度的记录，无法查看某个客户的学习情况，也无法处理账号问题（如停用、重置密码）。

产品决策

引入「客户账号」作为学习进度的唯一归属：注册 / 登录后才能产生并保存账号级学习记录；管理员通过客户管理查看这些记录，并对账号执行状态与安全操作。客户的学习情况允许各不相同，不做统一课程包或统一进度。

目标（可观察）

  • 客户注册并登录后，在另一台设备登录同一账号，能看到相同的课次完成、测评成绩与复习计划。
  • 管理员可按用户名找到客户，并在一个详情页看到该客户的课次完成率、单元完成度、测评记录和待复习数量。
  • 被禁用的客户无法继续登录，已登录会话立即失效；重新启用后学习记录原样恢复。
  • 删除客户后，该账号与其学习记录不可再访问，用户名可被重新注册。
旧版本地进度不迁移、不合并：登录后界面只展示账号进度；账号没有记录时显示为 0，而不是浏览器里残留的进度。

02范围

P0 是「客户能拥有自己的账号与进度，管理员能看到并管理这个账号」的最小完整闭环。

优先级能力说明
P0前台注册用户名 + 密码注册，成功即登录（FR-01）。
P0前台登录 / 登出 / 会话保持登录、登出、会话过期重新登录（FR-02）。
P0登录门槛与回跳浏览与试听开放；产生学习记录的动作需登录，登录后回到原页面（FR-03）。
P0账号级学习记录课次完成、课次测评、词条复习卡、句子复习卡、最近学习时间（FR-04）。
P0客户列表与检索分页列表、用户名搜索、状态筛选（FR-05）。
P0客户详情账号信息 + 学习概览 + 单元完成度 + 测评记录 + 待复习（FR-06）。
P0禁用 / 启用客户二次确认；立即失效会话；记录保留（FR-07）。
P0重置客户密码管理员设置新密码；旧密码与全部会话立即失效（FR-08）。
P0删除客户输入用户名二次确认；账号与学习记录不可恢复（FR-09）。
P1客户标签与备注管理员给客户打标签、记录沟通备注，用于跟进。
P1客户列表导出按当前筛选条件导出 CSV。
P1学员自助改密 / 找回需额外的身份验证通道，P0 由管理员重置。
不做第三方登录、短信 / 邮件验证P0 不引入外部账号与验证通道。
不做付费、班级、家长端与本次闭环无关。

03角色与对象

角色

角色定义能做什么
游客未登录访问者浏览首页、课程结构、单元与课次详情、词汇、句子、发音中心；试听音频。不能产生学习记录，不能进入测评与复习。
客户（学员）在前台注册成功的账号，也是客户管理中的「客户」学习课次、完成课次、参加课次测评、复习词条与句子；查看自己的进度；登出。
管理员中后台账号，与客户账号体系分离管理内容；在客户管理中查看 / 检索客户、禁用 / 启用、重置密码、删除客户。

对象

对象关键内容归属与生命周期
客户账号用户名、密码、状态（正常 / 禁用）、注册时间、最近登录时间属于一个客户；注册创建，删除销毁；状态可禁用 / 启用。
课次完成记录课次、首次完成时间按客户归属；同一课次只记一次，重复完成不重复计数。
课次测评记录课次、正确题数、总题数、提交时间按客户 + 课次归属；保留最近一次结果，重复测评覆盖展示值。
复习卡词条或句子、盒子 1–5、下次到期时间按客户 + 词条 / 句子归属；评分后更新盒子与到期时间。
最近学习时间最近一次学习行为发生时间由课次完成、测评提交、复习评分触发更新，用于列表排序。
登录会话会话标识、创建时间、失效时间按客户归属；登出、禁用、重置密码、删除时立即失效。

04核心流程

客户从注册到被管理的主路径；任一步失败都在对应功能需求里定义恢复方式。

入口游客浏览课程，点击需要登录的动作
→
注册 / 登录用户名 + 密码；注册成功即登录
→
学习课次、测评、词条与句子复习
→
记录按账号即时保存，跨设备可见
→
管理管理员检索客户、查看进度
→
处置禁用 / 启用、重置密码、删除

说明：客户的课程范围与进度互不影响；本流程不含任何统一排课或班级逻辑。

05功能需求

FR-01 前台注册

目的：让客户拥有可跨设备使用的账号，作为学习进度的归属。

入口：首页 / 导航「注册」；需登录动作被拦截时的登录页内「还没有账号？注册」。

字段与校验

字段必填规则错误提示
用户名是4–20 个字符，仅字母、数字、下划线；不区分大小写唯一；注册后不可修改。「用户名需 4–20 位，仅限字母、数字和下划线」/「该用户名已被使用」
密码是8–64 个字符，至少包含 1 个字母和 1 个数字，区分大小写；前后空格不参与校验。「密码需 8–64 位，且同时包含字母和数字」
确认密码是与密码完全一致。「两次输入的密码不一致」

处理规则

  • 提交时先做本地格式校验，全部通过后再提交；服务端校验用户名唯一性，冲突时保留已填内容并提示。
  • 注册成功后自动登录，跳转到注册前想去的页面；无来源页时进入首页。
  • 注册不要求邀请码、审核或邮箱 / 手机号验证。

结果与状态变化

  • 创建客户账号（状态「正常」），创建登录会话；学习记录为空，进度显示 0。
  • 管理员客户列表立即可见该客户，最近学习时间为空。
[Assumption, TBD] 同一 IP 每小时最多成功注册 10 个账号，超出提示「操作过于频繁，请稍后再试」。该阈值用于防批量注册，可在评审时调整。

FR-02 前台登录、登出与会话

目的：客户在任何设备上进入自己的学习记录。

登录

  • 输入用户名 + 密码；用户名校验不区分大小写，密码区分大小写。
  • 凭据错误统一提示「用户名或密码不正确」，不区分「用户不存在」与「密码错误」。
  • 同一用户名连续 5 次失败后锁定 15 分钟，期间即使密码正确也提示「尝试次数过多，请 15 分钟后再试」；成功登录后失败计数清零。
  • 状态为「禁用」的账号登录时提示「账号已被禁用，请联系管理员」，不创建会话。

会话

  • 登录成功后创建会话，有效期 7 天；有效期内访问前台自动保持登录。
  • 会话过期后访问需登录页面，跳转登录页并在登录成功后回到原页面。
  • 登出立即销毁当前会话并回到首页；不影响其他设备的会话。
  • 禁用、重置密码、删除客户时，该客户的全部会话立即失效（见 FR-07 / FR-08 / FR-09）。

导航展示

登录后导航显示用户名与「登出」；未登录显示「登录 / 注册」。同一浏览器只保留一个客户会话，登录另一个账号会替换当前会话。

FR-03 学习行为的登录门槛与旧进度处理

目的：保证所有可展示的进度都能归属到账号，同时不让游客在浏览阶段就被登录拦住。

无需登录（游客可用）

  • 首页、课程结构、单元与课次详情、词汇、句子、发音中心。
  • 试听词条、句子与课次内已有的音频。

需要登录

  • 开始课次学习、标记课次完成、提交课次测评。
  • 词条 / 句子复习评分，以及进入「进度」「复习」页面。
  • 任何会写入学习记录的动作。

游客触发受限动作时，弹出登录提示或跳转登录页；登录 / 注册成功后自动回到触发动作所在的页面，不自动执行原动作，由客户再次点击。

旧进度不合并（已确认）：登录后只读取账号的学习记录，不读取、不导入浏览器中已有的本地进度。账号记录为空时，进度页显示 0 / 总课次、无测评、无复习卡；本地旧数据不作为任何展示依据。

FR-04 账号级学习记录

目的：让「每个客户的学习情况都不一样」成为可保存、可查看的事实。

记录内容

记录写入时机规则
课次完成客户完成课次学习并点击完成同一课次仅保留首次完成时间；重复完成不新增记录、不改变完成时间。
课次测评提交课次测评保存正确题数、总题数与提交时间；同一课次重复测评时以最近一次为展示值。
词条复习卡复习评分「再练一次」或「记住了」盒子 1–5；评分后更新盒子与下次到期时间；未复习过的词条无卡片记录。
句子复习卡复习评分「再练一次」或「记住了」与词条相同的盒子规则，单独统计。
最近学习时间以上任一行为成功写入取最近一次行为时间，用于「最近学习」展示与列表排序。

课次、词条、句子以当前课程内容为准；内容被删除后，对应记录不再计入完成率与待复习数量，但保留在客户历史中不再展示明细。

进度指标（前台与中后台使用同一套计算）

指标计算规则空值表现
课次完成率已完成课次数 ÷ 当前全部课次数，向上取整到整数百分比。无课次数据时显示 0%。
单元完成度单元内已完成课次数 ÷ 该单元课次总数。单元无课次时不展示该单元。
测评平均正确率所有已测评课次的正确题数之和 ÷ 总题数之和，保留整数百分比。无测评记录显示「—」。
待复习词条 / 句子到期时间 ≤ 当前时间 的卡片数量；分别统计词条与句子。无到期卡片显示 0。
最近学习最近一次写入学习记录的时间。从未学习显示「—」。

同步与展示

  • 学习行为成功后即时保存到账号；客户在另一台设备登录同一账号可看到相同数据。
  • 前台进度页展示：已完成课次（x / 总课次）、待复习词条数、待复习句子数、各单元完成度。
  • P0 不提供离线学习与冲突合并；网络失败时提示重试，未成功写入的行为不计数。
  • 学习记录只由客户本人的学习行为写入；管理员不能代改、补录或清除单个记录。

FR-05 中后台客户列表与检索

目的：管理员能快速找到某个客户，并一眼判断其状态与学习活跃度。

布局

顶部为搜索与筛选；中部为列表；底部为分页。列表列固定为：用户名、状态、课次完成、待复习、最近学习、注册时间、操作。

处理规则

  • 默认排序：最近学习时间倒序；从未学习的客户排在后面，按注册时间倒序。
  • 搜索：按用户名模糊匹配，不区分大小写，去除首尾空格；输入后点击搜索或回车生效。
  • 状态筛选：全部（默认）/ 正常 / 禁用。
  • 分页：每页 20 条，显示总条数与页码；筛选条件在翻页时保留。
  • 「课次完成」显示「已完成数 / 总课次」；「待复习」显示词条数与句子数合计；「最近学习」显示相对时间（如「2 天前」），悬停显示具体时间。
  • 操作列提供「查看」，进入客户详情（FR-06）。

空状态与异常

  • 无任何客户：「还没有客户，客户在前台注册后会出现在这里」。
  • 筛选 / 搜索无结果：「没有匹配的客户」，提供「清除筛选」。
  • 加载失败：显示错误与「重试」，保留当前筛选条件。

FR-06 客户详情

目的：回答「这个客户学得怎么样、学到哪、卡在哪」。

页面结构

  1. 账号信息：用户名、状态、注册时间、最近登录时间、最近学习时间；右上角为操作入口（禁用 / 启用、重置密码、删除）。
  2. 学习概览：课次完成率、已完成课次（x / 总课次）、测评平均正确率、待复习词条数、待复习句子数。
  3. 单元完成度：按单元顺序列出每个单元的已完成 / 总课次与进度条；未开始的单元同样展示为 0%。
  4. 课次明细：已完成课次列表（课次名称、首次完成时间）；已测评课次列表（课次名称、正确题数 / 总题数、正确率、提交时间）。无记录时分别显示空状态。
  5. 复习卡摘要：词条与句子各显示总数、各盒子数量、当前到期数量；不展示逐条卡片内容。

规则

  • 详情只读；不提供编辑学习记录、代打卡、重置单个课次进度的能力。
  • 从列表进入时保留来源筛选与页码，返回列表回到原位置。
  • 客户被删除后再次访问该详情，提示「客户不存在或已被删除」并返回列表。
[Assumption, TBD] 客户详情不展示客户密码、登录 IP 与设备信息；如后续需要安全排查，再单独定义。

FR-07 禁用 / 启用客户

目的：在不删除学习记录的前提下，阻止某个客户继续使用账号。

禁用

  • 入口：客户详情操作区、列表操作列；点击「禁用」弹出二次确认，说明「禁用后该客户将立即退出登录且无法再登录，学习记录会保留」。
  • 确认后：账号状态变为「禁用」；该客户全部会话立即失效；后续登录被拒（提示见 FR-02）。
  • 禁用不改变学习记录、不改变最近学习时间、不影响列表排序依据以外的数据。

启用

  • 对「禁用」客户显示「启用」，确认后状态恢复「正常」；客户可重新登录，原学习记录原样可见。
  • 启用不自动创建会话，客户需自行登录。

列表与详情的状态标签：正常 / 禁用。操作成功后即时刷新当前页面并提示结果。

FR-08 重置客户密码

目的：客户忘记密码且 P0 无自助找回时，由管理员恢复其登录能力。

流程

  • 客户详情操作区点击「重置密码」，弹窗要求管理员输入新密码并再次确认；密码规则与注册一致（8–64 位，至少 1 个字母和 1 个数字）。
  • 提交前提示「重置后旧密码立即失效，该客户所有设备将被退出登录」。
  • 确认后：新密码立即生效；该客户全部会话失效；学习记录不变。
  • 成功后弹窗关闭并提示「密码已重置，请将新密码告知客户」；管理员需自行通过线下或其他渠道告知客户。

不允许管理员查看客户当前密码；不提供「以客户身份登录」的模拟功能。

FR-09 删除客户

目的：彻底移除不再合作的客户及其学习数据。

删除是不可恢复操作。账号、登录会话与全部学习记录一并消失，且不保留可恢复副本。

流程

  • 客户详情操作区点击「删除客户」，弹出确认框，要求输入完整用户名后才能确认删除；输入不一致时确认按钮不可用。
  • 确认框明确列出影响：账号无法再登录、学习记录与复习计划一并删除、用户名可被重新注册、操作不可撤销。
  • 确认后：删除账号与学习记录；该客户全部会话立即失效；返回客户列表并提示「客户已删除」。
  • 删除后使用同一用户名重新注册，视为全新客户，进度从 0 开始。

客户管理只能删除客户账号，不能删除管理员账号；管理员账号不在客户列表中展示。

会话与安全规则

  • 会话有效期 7 天；登出、禁用、重置密码、删除客户时立即失效。
  • 密码不展示、不可查看；重置密码只接受符合规则的新密码。
  • 用户名唯一且注册后不可修改；大小写不同的同名视为同一用户名。
  • 客户账号与管理员账号完全分离：客户不能进入中后台，管理员账号不出现在客户管理列表。
  • 删除客户为不可恢复操作，必须输入完整用户名确认；禁用、重置密码为可恢复 / 可再操作动作，需二次确认。

08异常与边界

场景表现与处理
注册时用户名并发被占用服务端返回用户名已存在；保留其他已填内容，聚焦用户名字段并提示。
登录连续失败触发锁定15 分钟内拒绝该用户名登录；提示剩余等待时间，不透露账号是否存在。
会话过期时正在学习保存动作被拒，提示「登录已过期」，跳转登录页；登录成功后回到原页面，由客户重新提交，不自动补记。
客户在另一设备被禁用当前页面继续可浏览，但下一次写入学习记录或访问需登录页面时被拒，提示「账号已被禁用」并退出登录。
网络失败导致记录未保存提示重试；该次完成 / 测评 / 复习不计入进度，重试成功后再计入。
客户无任何学习记录进度页显示 0 / 总课次、无测评、待复习 0；中后台详情显示空状态，不显示错误。
课程内容被删除对应课次不再计入完成率分母与已完成数；历史测评与复习卡不再展示明细。
管理员删除客户后刷新详情提示「客户不存在或已被删除」，返回客户列表。
重复提交完成 / 测评完成只记首次；测评以最近一次为展示值；复习评分按最后一次更新卡片。
管理员误删客户删除不可撤销；确认框要求输入完整用户名，并在按钮上方持续显示不可恢复提示。
