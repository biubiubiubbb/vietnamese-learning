Product Requirements Document

课程详情拆分为「学习页」与「练习页」

把「学一个练一个」的长页结构改为「先完整学习、再集中练习」，学习与练习各自成为独立页面。

版本v0.1 草案 日期2026-11-02 负责人[TBD] 涉及模块课程详情、课程地图、首页入口 文档类型常规 PRD（功能迭代）

1背景与目标

现在的问题

课程详情是一个长页面：词汇 → 句子 → 句子练习 → 语法 → 对话 → 课文练习。其中「句子练习」被嵌在句子板块内部，学习者刚读完几个句子就被要求做题，节奏变成「学一个、练一个」。

整页唯一的集中练习区又压在页面最底部，课程内容一多，学习者需要长距离滚动才能找到练习；页面缺少「学习区 / 练习区」的边界。

期望的结果

学习者进入一门课时，先看到完整、连续、不打断的学习内容，页面里不出现任何作答控件；学完后通过一个明确入口进入练习页，本课所有题目集中在一处完成。

练习不强制要求先学完，复习时可以直接进入练习页。

产品判断

采用「独立页面」而不是同页分区，是本次需求明确的选择：学习与练习拥有各自的路由、各自的页面目标，避免练习入口再次被长页内容掩埋。

2范围

本次只调整课程详情的信息架构与入口，不新增、不改写任何课程内容。

优先级内容说明
P0 学习页 /lesson/:lessonId 承载词汇、句子、语法、对话；移除页面内全部作答控件。
P0 练习页 /lesson/:lessonId/practice 集中承载本课的「句子练习」与「课文练习」，承担完成本课的盖章动作。
P0 两页互跳与课程完成流转 学习页底部进入练习；练习页顶部返回学习；完成后进入下一课学习页。
P0 既有入口改造 首页、课程地图、上下课导航、今日任务全部指向学习页。
P1 练习作答进度持久化 刷新或返回后恢复已答题目与得分，而不是重新作答。
不做 全局练习页 /practice 听词选义、听句选中文等五种模式保持不变，不在本次范围内。
不做 课程内容与题库 词汇、句子、语法、对话、题干与答案均不改动，仅改变展示位置。
不做 复习页、发音页、词汇页 不受本次改动影响。

3产品模型与核心流程

3.1 对象与路由

对象 / 路由定义状态
Lesson 一门课，由 lessonId 唯一标识，包含词汇、句子、语法、对话、课文练习与句子练习。 未完成 / 已完成
/lesson/:lessonId 学习页：本课学习内容的唯一展示页面。 —
/lesson/:lessonId/practice 练习页：本课全部题目的唯一集中练习页面。 未作答 / 作答中 / 全部作答

课程「已完成」状态沿用现有本地进度记录，语义不变，仅触发位置从学习页迁移到练习页。

3.2 核心流程

首页 / 课程地图 → 学习页 → 练习页 → 完成本课 → 下一课学习页

练习页可直接通过链接访问，不校验学习完成度；学习页与练习页可随时互相返回。

4功能需求

FR-01 学习页

P0

路由 /lesson/:lessonId；目标是让学习者连续读完本课全部新内容，不被作答打断。

1页面头部

返回课程地图；级别 · 单元 · 第几课标签；课程标题；本课目标；已完成课程额外显示「已完成 ✓」章。

2词汇

词汇卡片网格，点击卡片发音；标题右侧圆形徽章显示词数。超过 18 个词时默认折叠，提供「展开全部 / 收起」。

3句子

只保留学习能力：句子朗读、中文对照开关、词块「拆解」与逐句注释。不再包含任何句子练习。

4语法

语法说明、例句与提示条，与现状一致。

5对话

对话全文、整段朗读、中文对照开关，与现状一致。

6底部行动区

主按钮「去练习 · N 题 →」进入练习页；N 为本课句子练习与课文练习的总题量。下方保留上一课 / 下一课导航。

规则项行为
作答控件学习页不出现提交、判断、计分等任何作答控件；「拆解」属于学习交互，保留。
学习是否改变进度不改变。翻阅学习内容不写入已完成状态，也不产生得分。
已完成课程顶部显示「已完成 ✓」，底部主按钮文案改为「再练一次 →」，点击进入练习页。
内容缺失某课没有语法、对话或句子时，对应区块整体隐藏，不留空标题。
课程不存在重定向到课程地图 /learn。

FR-02 练习页

P0

路由 /lesson/:lessonId/practice；目标是让本课所有题目集中在一处完成，并在这里结束本课。

1页面头部

「← 返回学习」链接；课程标识与标题；练习总进度「已答 X / N」；已完成课程显示状态章。

2句子练习

从学习页迁移过来的句子练习（挖空、词序、中译越），保留即时判定与解析。

3课文练习

原有的选择题与填空题，保留即时判定与解析。

4完成区

本课全部题目作答后出现：课文练习得分、评价文案、完成本课按钮（未完成课）或「下一课」入口（已完成课）。

规则项行为
进入条件不校验学习完成度，任何学习者都可直接进入；已完成课程也可再次进入重做。
题目范围句子练习在前、课文练习在后；两区分别显示各自题量。
总进度顶部「已答 X / N」中，X 为两个区已作答题数之和，N 为两区题目总数。
完成条件课文练习全部作答后出现「完成本课」按钮；句子练习是否计入完成条件见第 6 节待确认项。
点击完成写入已完成记录，显示盖章状态，并提供「下一课」入口。
重复进入已完成的课程再次完成不会重复计数；盖章只展示，不重复记录。
中途离开本次作答状态不持久化，刷新或重新进入后从头作答；已完成与得分记录持久保留。
无题目某课没有练习题时显示空状态与「返回学习」入口，不显示完成按钮。
课程不存在重定向到课程地图 /learn。
边界说明

「完成本课」只发生在练习页，学习页不再提供盖章按钮；学习页的已完成状态只做展示。

FR-03 入口与导航改造

P0
位置改动后行为
首页主按钮「继续 / 开始第一课」仍指向下一课学习页，文案不变。
首页今日任务「学 1 新课」指向下一课学习页。
课程地图单元卡片指向该单元第一门待学课程的学习页，行为不变。

学习页上一课 / 下一课仍指向相邻课程的学习页；上一课 / 下一课不会跳转到练习页。
练习页顶部「← 返回学习」回到本课学习页。
练习页完成区「下一课」指向下一课学习页；已是最后一课时回到课程地图。
顶栏「课程」导航仍指向 /learn，不变。

FR-04 完成与状态

P0
状态学习页练习页首页 / 课程地图
未完成 无常驻章；底部「去练习」 可作答；答完出现「完成本课」 计入未完成课程，作为「继续学习」候选
已完成 顶部「已完成 ✓」；底部「再练一次」 显示已完成；可重做；提供「下一课」 计入已完成进度与总课数

课程分数沿用现有记录方式：课文练习答对题数 / 课文练习题数，在点击「完成本课」时写入。

5共享规则与异常

规则定义
题量统计句子练习 = 本课句子关联练习题；课文练习 = 本课 exercises。总题量 = 两者之和，全站统一使用该口径。
完成记录只记录「课程 ID + 完成时间 + 分数」，不因重复完成而新增记录。
路由约定学习页与练习页共享同一 lessonId；未带 lessonId 或课程不存在时统一回课程地图。
作答状态题目作答状态属于页面会话；完成记录与得分属于持久进度。两者不混用。
内容零改动拆分过程中不调整任何词条、句子、语法、对话与题目的内容或顺序。
回归检查点

拆分后需确认：句子「拆解」仍可用、整段朗读仍可用、词汇折叠仍可用、练习判定与解析仍与拆分前一致、已完成课程的章与分数仍正确显示。
