1背景与目标

前端学习流程已经可用，但内容仍然是代码的一部分。

现状。前端包含 8 个单元、25 节课、152 个词条、75 个句子；发音中心包含 29 个字母、6 个声调、4 组易混音、8 组最小对立体、4 条标调规则。朗读音频由脚本预生成：530 条文本 × 女声 / 男声 = 1,060 个片段。

问题。改文案、调顺序、补音频都要改代码、重新构建、重新生成音频；运营无法独立维护。文本与音频分开维护后，容易出现“页面显示新句子、音频仍是旧句子”的不一致。

产品决策。建设中后台，把学习内容与音频作为统一内容资产持久化管理；保存立即生效；后台沿用前端的手账视觉语言，但信息密度更高、操作更克制。

目标结果。管理员不改代码即可完成内容增删改、排序、双音色音频生成 / 替换与基础配置；前端始终读取同一份最新内容，音频缺失时仍能正常学习。

“可朗读文本”包括词条、例句、句子、词块、语法例句、对话台词、练习音频文本、字母名称、声调示例、易混音示例与最小对立体。只要文本变化，对应音频即进入待更新。

4核心流程

4.1 编辑并保存

进入列表 / 详情→ 编辑字段→ 实时校验→ 保存→ 前端立即生效

保存前不写入。保存成功后展示“已保存 · 刚刚”，列表与详情立即更新；若跳转到前端页面，应能看到同一版本。

4.2 文本变更后的双音色音频

保存可朗读文本→ 旧音频标记「待更新」→ 女声 / 男声进入队列→ 生成中→ 双音色就绪，替换旧音频
生成中→ 生成失败→ 旧音频继续可用 + 重试入口

旧音频在新音频就绪前保持可播放，避免学习者中途遇到无声；失败不会自动停用旧音频，但会在总览与音频列表标红。

4.3 删除与恢复

点击删除→ 依赖检查→ 存在引用：阻止并列出
无引用→ 二次确认→ 进入回收站→ 恢复 / 永久删除

删除不会追溯到学员进度；但内容 ID 不复用，避免恢复后与学习记录错位。

5功能需求

功能需求是本文件的主体。所有模块共享的保存、ID、音频、删除与校验规则统一见第 7 节，本节只描述模块自身行为。

FR-01登录与总览P0

目的：让唯一管理员进入后台，并在一屏内判断“内容是否完整、音频是否健康、今天该处理什么”。

入口与布局：后台使用独立后台账号与密码登录，不沿用学员账号体系，也不开放注册；账号在项目初始化时创建。未登录访问任何后台页面都先进入登录页，登录后默认进入总览。总览顶部为四个指标卡，下面左侧为“音频健康”，右侧为“最近修改”，底部为快捷操作。

区域内容规则
内容指标单元 / 课程 / 词条 / 句子数量点击指标进入对应列表；数量为当前线上数据
发音指标字母、声调、易混音、最小对立体、标调规则数量与发音中心列表一致
音频健康待生成、生成中、待更新、失败、已停用数量点击任一状态跳到音频列表并带上筛选
最近修改最近 10 条内容及时间、模块、操作按保存时间倒序；只显示当前可见数据
快捷操作新增词条、新增课程、生成缺失音频、打开前端“打开前端”在新标签页打开首页

异常：加载失败时展示“数据暂时加载失败”与重试按钮，不展示过期缓存；无任何内容时展示“先导入现有内容”的引导。

FR-02课程结构：单元与课程P0

目的：维护前端课程地图、单元页和课程页的层级与顺序。

列表：单元按 A1、A2 分组，再按顺序排列；每个单元显示标题、副标题、课程数、完成状态（仅用于编辑提示，不展示学员进度）。展开单元可看到课程列表。

对象字段规则
单元ID、级别、顺序、标题、副标题ID 创建后不可改；顺序支持拖拽；同级别内顺序唯一
课程ID、所属单元、顺序、标题、学习目标顺序支持拖拽；同一单元内顺序唯一；可移动到其他单元
课程关联词汇、句子、语法、对话、练习通过课程编辑页管理；删除课程前必须先处理其下句子

删除约束：单元下仍有课程时不能删除，提示先移动或删除课程；课程下仍有句子时不能删除，提示句子列表。删除进入回收站，恢复时若原顺序已被占用，则追加到末尾并提示。

结果：保存后课程地图、单元页、课程页立即按新结构展示；移动课程后，旧单元与新单元同时更新。

FR-03词汇库P0

目的：维护 152 个词条及其例句、标签、汉越信息，并让课程与句子能引用同一份词条。

列表：支持关键词搜索（越南语、中文、ID）、按标签与词性筛选、按音频状态筛选；表格列包含越南语、中文、词性、标签、使用次数、女声 / 男声状态。默认每页 20 条，可切换 50 / 100。

字段必填规则
ID是创建时自动建议，允许自定义；保存后不可修改，不可复用
越南语是去首尾空格；为空不可保存；与已有词条重复时提示但允许保存
中文是展示在前端词条释义
词性是名词、动词、形容词、副词、代词、数词、量词、介词、连词、助词、短语
汉越否为空时前端不显示汉越标签
例句否越南语与中文成对填写；只填一边不可保存
注释否前端以 ※ 展示
标签否可多选：核心高频、问候、称谓、数字、时间、家庭、购物、饮食、出行、工作、爱好、语法

引用与删除：详情页展示“被哪些课程引用”“被哪些句子词块引用”。被引用时禁止删除，提供“查看引用”跳转；解除引用后可删除，进入回收站。

结果：保存后词汇页、课程词汇区、句子词块的汉越提示同步更新；修改越南语或例句会触发对应音频进入待更新。

一致性提示：句子词块与词条是引用关系，不自动同步文本。修改词条越南语时，列出关联词块并询问是否一并更新词块文本；不更新时保留词块原文，但标记为“引用词条文本不一致”，避免前端出现词条与句子写法不同。

FR-04句子与句子练习P0

目的：维护句子的词块拆解与三类练习，保证拆解、答案和音频始终与句子文本一致。

列表：按课程分组，支持按句型（陈述、疑问、否定、请求、感叹）和音频状态筛选；每行显示句子、中文、句型、词块数、练习数、双音色状态。

句子编辑：基础字段包含所属课程、顺序、越南语、中文、句型、注释。词块可拖拽排序，每个词块包含越南语、中文、语法角色（主语 / 谓语 / 宾语 / 修饰 / 时间 / 地点 / 语气）与可选词条关联。

练习类型字段校验
挖空被挖空的词块、答案、可接受答案、提示、解析词块必须属于当前句子；答案非空；可接受答案去重
词序正确词块顺序、解析顺序必须包含每个词块恰好一次，数量与词块数一致
中译越参考答案、可接受答案、提示、解析答案非空；可接受答案去重

联动规则：增加、删除或重排词块后，已有“挖空 / 词序”练习的答案可能失效，保存前必须重新确认；未确认时阻止保存并逐条标出受影响练习。

文本一致性：保存前校验词块按顺序拼接（空格分隔、忽略首尾标点与多余空格）是否等于句子越南语；不一致时阻止保存，并标出差异位置。避免句子上屏文本与拆解词块、整句音频互相矛盾。

结果：句子列表、课程句子区、复习牌堆立即更新；句子文本或词块文本变化会触发整句音频待更新。

FR-05课程内容：语法、对话、课程练习P0

目的：在课程编辑页集中维护不属于词条与句子的内容块。

语法点

字段必填规则
标题是课程内可拖拽排序
讲解是支持纯文本；前端按段落展示
例句否越南语与中文成对；每条例句有独立试听按钮
提示否可多条，前端逐条以 ※ 展示

对话

对话包含标题与台词列表。台词字段为说话人、越南语、中文，支持拖拽排序。前端“整段朗读”按说话人首次出场顺序交替女声 / 男声；首位说话人使用全局默认音色。管理员不需要逐句指定性别，只需保证说话人名称一致。

课程练习

类型字段校验
选择题题干、音频文本、选项、正确答案、解析至少 2 个选项；正确答案必须指向一个选项；选项去重
填空题题干、音频文本、答案、可接受答案、提示、解析答案非空；可接受答案去重

结果：课程页的语法、对话、练习立即更新；对话台词、语法例句与练习音频文本变化会触发双音色音频待更新。

FR-06发音中心P0

目的：维护发音页五个子模块，并保证页面标题中的数量与列表实际数量一致。

29 个字母

字母、名称、IPA、中文近似、注释；名称用于朗读。页面标题改为读取实际数量，不再写死“29”。

6 个声调

名称、调号、示例音节、声调曲线、中文感受、示例词；曲线编辑后即时预览。

易混音组

组标题与组内条目；条目包含音、IPA、中文近似、示例词、注释。

最小对立体 / 标调规则

最小对立体含两个词、两个中文、辨析点；标调规则含标题、正文、示例。

校验：名称为空不可保存；声调曲线必须是可渲染的 SVG 路径，保存前预览失败则阻止保存；最小对立体必须恰好两个词；标调规则正文不能为空。

结果：发音页五个区块立即更新；字母名称、声调示例、易混音示例、最小对立体词语变化会触发对应双音色音频待更新。

FR-07音频管理P0

目的：让管理员能看清每条可朗读文本的双音色状态，并在文本变更、生成失败或音色不理想时快速修复。

列表：按“文本 + 音色”展示；支持搜索文本、按状态（待生成 / 生成中 / 已就绪 / 待更新 / 失败 / 已停用）、按来源（自动生成 / 后台录音）、按使用位置筛选。

字段 / 操作规则
朗读文本来自内容对象，只读；点击可跳到首个使用位置
女声 / 男声各自独立状态；可单独试听、重新生成、录音、停用
来源自动生成或后台录音；录音后仍可重新生成
使用位置显示引用该文本的内容对象数量与清单
重新生成生成中保留旧音频；成功后原子替换；失败保留旧音频并标红
后台录音选择女声或男声 → 麦克风授权 → 录制 → 试听 → 保存替换；支持停止、重录、取消；时长不限
停用停用后前端不使用该音色，回退到另一音色；两个都停用时回退系统语音

自动生成：任何可朗读文本保存后，系统自动为女声、男声分别排队生成，不需要管理员手动触发，也不提供上传入口。同一文本 + 同一音色只保留一个资产，多个引用共享，修改任一引用文本只影响该文本的新资产。

后台录音：管理员选择女声或男声后点击“录音”，浏览器请求麦克风权限；录制中显示计时与波形，可停止或取消。停止后进入试听确认，保存才替换线上音频；未保存离开时提示确认。录制前暂停其他试听，避免把后台播放声录进去。录音时长不设上限，由管理员手动停止。

试听：在后台直接播放对应音色；试听不改变状态，也不影响前端正在播放的内容。

失败与重试：失败展示原因摘要与重试按钮；连续失败在总览汇总，不阻断内容保存。麦克风权限被拒绝、无输入设备或录音解码失败时，保留原音频并提示检查设备后重试。

FR-08全局配置P0

目的：只保留真正需要调整的播放配置；生成策略与兜底策略固定，避免后台出现“关了开关导致无声”的状态。

配置项可选值生效规则
默认音色女声 / 男声影响普通朗读与对话首位说话人；保存后下一次播放生效
文本自动生成音频固定开启任何可朗读文本保存后自动生成女声、男声，不提供关闭
音频缺失时前端兜底固定开启兜底顺序：当前音色音频 → 另一音色音频 → 浏览器系统语音

结果：配置保存后立即写入线上；播放中的音频不被打断，下一次朗读使用新配置。

FR-09初始化导入P0

7共享规则

以下规则在多个模块复用，功能章节不再重复定义。

编号规则具体行为
S-01保存立即生效保存前实时校验；成功后写入线上并立即对前端生效。展示“已保存 · 刚刚”，列表与详情同步刷新。无草稿、无审批。保存失败保留已填内容并提示重试。
S-02ID 稳定内容创建时生成建议 ID，允许自定义；保存后不可修改、不可复用。删除后 ID 不释放，避免学员进度与内容错位。
S-03音频生命周期状态为：待生成 → 生成中 → 已就绪；文本变化后进入待更新；生成失败进入失败；管理员可停用。停用不删除资产。
S-04文本变更触发音频更新任何可朗读文本保存后，女声与男声同时进入待更新并排队生成；旧音频在新音频就绪前继续服务前端。
S-05同名文本复用音频同一“文本 + 音色”只保留一个音频资产，多处引用共享；音频详情展示全部使用位置。
S-06播放回退音频缺失、待生成、生成失败或停用时，前端按“当前音色音频 → 另一音色音频 → 浏览器系统语音”依次回退；两个音色都不可用时使用系统语音。
S-07删除与依赖有子级或被引用的内容禁止直接删除；先解除引用或处理子级。无依赖内容软删除进入回收站，可恢复。
S-08并发编辑打开编辑后若该记录已被其他标签页保存，本次保存被阻止，展示“内容已更新，请刷新后重新编辑”。不允许静默覆盖。
S-09保存前校验必填、唯一性、范围、引用、练习答案与 SVG 路径均在保存前校验；句子词块拼接必须与句子越南语一致；错误定位到具体字段并保持滚动位置。
S-10列表行为搜索匹配越南语、中文、ID 或标题；筛选条件可组合；显示结果数；无结果展示空态；分页默认 20 条，可切换 50 / 100。
S-11录音约束录音需麦克风授权，录制中显示计时与波形，停止后先试听再保存；单条录音不设时长上限，由管理员手动停止；录音替换不改变朗读文本，只改变音色来源；本期不提供音频上传。

10已确认决策

以下决策已确认，并写入对应功能与共享规则；如后续改变，需要同步更新 FR-07、FR-08、FR-09、S-06 与 S-11。

决策内容对需求的影响
管理员登录使用独立后台账号与密码，不沿用学员账号体系，不开放注册；后台只有一个管理员账号。登录页独立；不做角色、审批与注册找回。
音频来源不提供音频上传。任何可朗读文本保存后，系统自动生成女声与男声；保留后台录音替换能力。音频来源只有“自动生成”和“后台录音”；删除上传相关入口与校验。
生成失败兜底不建设备用音色服务。后台没有音频、生成失败或音色被停用时，前端按“当前音色 → 另一音色 → 浏览器系统语音”兜底。生成失败不阻断内容保存；前端始终有声音。
上线方式项目仍在开发中，不考虑上线切换、维护窗口或回滚流程。初始化导入后，后台数据直接作为前端唯一数据源。
录音时长单条录音不设时长上限，由管理员手动停止。不做录音超时自动停止与超时提示。
默认语速暂不提供后台配置，沿用前端现有朗读语速。全局配置只保留默认音色与固定生成 / 兜底策略。
