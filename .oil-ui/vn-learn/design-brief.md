# 设计说明：越语学堂（越南语学习网站）

## 产品事实
- 用户：中文母语者，零基础到入门（A1–A2），学习越南语
- 任务：学课程、练发音、背单词、做练习、看进度
- 内容：8 单元 / 25 课 / 约 300 词条 / 约 90 道题
- 设备：桌面 1440 主视口，兼容 375 移动端
- 发音：Web Speech API `vi-VN`，不依赖录音文件
- 技术：Vite + React + TS（已初始化，依赖已装好）

## 北极星
「打开一本手绘越南旅行手账」——每节课是一页手账，有纸纹、粗描边、硬投影、手写批注感；学习像闯关打卡，而不是填表。

## 主角与主动作（各屏）
- 首页：主角=「开始第一课」大按钮；主动作=进入课程。降级：浏览单元卡。
- 课程地图：主角=单元卡；主动作=进入下一课。
- 单课：主角=词汇/对话/练习内容；主动作=完成本课。侧栏课次导航降级。
- 发音中心：主角=6 声调曲线表；主动作=点读对比。
- 词汇：主角=闪卡；主动作=翻面评价。
- 进度：主角=完成度数据；主动作=回到下一课。

- 交互参考：Duolingo 练习流（凭记忆，未取图）。沿用：选项即点即判、即时反馈、进度条。调整：不做生命值/体力系统。

## 结构
- 顶栏：Logo 章 + 5 个导航 Tab（首页/课程/发音/词汇/进度），右侧「今日待复习 N」徽章
- 首页：欢迎手账页（大标题+开始学习）→ 学习路径三关 → 单元网格
- 单课：左主栏（目标→词汇→语法→对话→练习→完成打卡），右侧栏（本单元课次清单）
- 发音中心：声调曲线表（6 行 SVG 调型+普通话对照+点读）→ 字母网格 → 难点音 → 最小对立体
- 词汇：搜索+筛选 → 词卡网格 / 复习 Tab（闪卡）
- 进度：三个统计章 + 单元进度条列表

## 验收重点
- 越南语变音符（ă â ê ô ơ ư đ + 5 个声调符）渲染完整不被裁切
- 粗描边+硬投影风格全站一致
- 375px 无横向滚动
